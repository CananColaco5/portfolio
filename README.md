This folder is a complete static website. Open index.html in a browser to preview it.

  index.html          Home
  doc-platform.html   Digital Operations Center case study
  cityquest.html      CityQuest case study
  research.html       Research & Publications
  about.html          About
  assets/             Images and videos

Put it online (pick one)

1) Netlify Drop (fastest, free, no account needed to try)
   - Go to https://app.netlify.com/drop
   - Drag this whole folder onto the page.
   - You get a link like https://something.netlify.app. Create a free account to keep it
     and rename it (Site settings > Change site name), e.g. canan-colaco.netlify.app.

2) GitHub Pages (free)
   - Create a public repository, e.g. "portfolio".
   - Upload all files in this folder (keep the assets folder).
   - Settings > Pages > Source: "Deploy from a branch", branch "main", folder "/ (root)".
   - Your site appears at https://<your-username>.github.io/portfolio/

3) Your own domain
   - Any web host works: upload the contents of this folder to the public web root.
   - Netlify and GitHub Pages can also connect a custom domain you own.
